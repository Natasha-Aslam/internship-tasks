# Internship Tasks: Data Analysis & ML

## Objective
- Predict bank customer churn using historical data.
- Help the bank understand which customers may leave.

## Approach
1. Data Cleaning: Handle missing values and fix data types.
2. Exploratory Data Analysis: Visualize data using plots.
3. Model Building: Train Random Forest and Logistic Regression.
4. Evaluation: Check accuracy and confusion matrix.

## Results & Insights
- Customers with high loans or low account balances tend to churn.
- Age and credit history length are important factors.
- Model accuracy: 85%

## Folder Structure
- `datasets/` → Raw data files (CSV)
- `notebooks/` → Jupyter notebooks for tasks
- `scripts/` → Python scripts
- `reports/` → Plots, charts, PDFs
